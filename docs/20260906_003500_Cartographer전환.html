그대로인 것

차, 조이스틱(2번/MODE, 왼쪽 스틱), 라이다, 속도 한도. 카메라 없음. 집 맵 파일은 이미 지운 상태.

바뀌는 것

지금까지 (RTAB-Map)이제 (Cartographer)
맵을 그리는 프로그램RTAB-Map + scan_to_mapCartographer 2D 하나
옆장 맞춤우리가 짠 검색프로그램 안 실시간 스캔 맞춤
같은 장소 루프꺼져 있음 / 약함서브맵을 나중에 다시 붙여 각도를 당김
칸찍고 안 지움 (부채)확률 격자. 루프 후 다시 그림
바퀴 오돔 TFEKF가 odom 발행안 씀. Cartographer가 자세를 맡음
켜는 명령rtabmap_managed.launch.pyscripts/start_cartographer.sh
보이는 맵/map (scan_to_map)/map (Cartographer)

짧은 집 한 바퀴에서 출발 벽에 돌아오면, 예전 서브맵과 맞춰 경로를 한 번에 고치는 것이 목적입니다. 그게 RTAB에서 안 되던 부분입니다.

켜기 / 끄기

매핑: bash ~/ROSMASTER-R2-fork/scripts/start_cartographer.sh
끄기(맵 저장 후): bash ~/ROSMASTER-R2-fork/scripts/stop_robot_stack.sh
순찰: bash ~/ROSMASTER-R2-fork/scripts/start_patrol.sh
