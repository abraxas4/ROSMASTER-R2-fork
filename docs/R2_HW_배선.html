보드 구성

R2 차체 쪽 보드는 역할이 나뉩니다. STM32 보드와 USB HUB 보드는 별도 PCB이며, 둘 사이에 2핀(+/-) 전원과 USB(시리얼)가 연결됩니다. 카메라·라이다는 HUB를 거쳐 Jetson으로 갑니다.

데이터 경로 요약

ROS2 노드 간(④)은 주로 같은 Jetson 프로세스끼리 DDS. 다른 PC와도 가능.

물리: ROS/STM32 보드와 USB HUB 보드는 별도 PCB. 둘 사이 — 2핀 하네스 (+/− 전원) 와 USB(차체 시리얼 데이터). 카메라·라이다는 HUB → Jetson. 모터 등은 STM32 보드. HDMI는 Jetson. 참고: 소개 매뉴얼 Wiring diagram · 실물 실크 +/-.
